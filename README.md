# SOURAV — Architect of Futures

A futuristic portfolio website with cyberpunk aesthetics, featuring custom cursor, particle canvas, and smooth animations.

## Tech Stack
- Pure HTML/CSS/JavaScript
- Google Fonts (Orbitron, Syne)
- Canvas API for particle effects

## Features
- Custom animated cursor with trail effect
- Animated orb with orbiting nodes
- Typewriter text animation
- Scroll reveal animations
- Particle network background
- Responsive design
